Python library calls · page 1

Built-in Python libraries

These libraries arrive with Python. You import the toolbox, then use a dot to call a tool from inside it.

Built into Python
1 · IMPORT

Bring the library into your program.

2 · CALL

Use a named tool from that library.

3 · DOES

See the job that tool performs.

The dot matters: in random.randint(), the dot means “go into random and use randint.”

random

Chance and random choices

IMPORT

import random

CALL

number = random.randint(1, 10)

randint means “random integer”.

DOES

Chooses a whole number from 1 to 10. Both 1 and 10 are possible.

math

Extra mathematical tools

IMPORT

import math

CALL

answer = math.sqrt(81)

sqrt means “square root”.

DOES

Finds the square root of 81, giving the answer 9.0.

datetime

Dates and times

IMPORT

import datetime

CALL

today = datetime.date.today()

DOES

Gets today’s date from the computer.

statistics

Averages and middle values

IMPORT

import statistics

CALL

average = statistics.mean([4, 7, 10])

DOES

Calculates the mean average of the numbers, giving 7.

pathlib

Files and folders

IMPORT

from pathlib import Path

CALL

file = Path("notes.txt")
exists = file.exists()

DOES

Represents a file path, then checks whether that file exists.

json

Structured text data

IMPORT

import json

CALL

text = json.dumps({"name": "Phil"})

DOES

Turns a Python dictionary into JSON text that can be saved or sent.

csv

Comma-separated table files

IMPORT

import csv

CALL

reader = csv.reader(file)

DOES

Reads rows from an open CSV file. Each row is returned as a list.

collections

Special containers

IMPORT

from collections import Counter

CALL

counts = Counter(["red", "blue", "red"])

DOES

Counts repeated items. Here, red appears twice and blue once.

Python’s standard library gives you useful tools without installing extra packages.
